# Power BI Superstore Executive Sales Dashboard

## Business Questions
- How much are we selling?
- Are we actually profitable?
- Which categories and regions perform best?
- Which products drive the most revenue?

## Dashboard Features
- KPI cards: Sales, Profit, Orders, Profit Margin
- Monthly sales trend
- Sales by Category
- Profit by Region
- Top 8 Products by Sales
- Interactive filters (Region, Category, Year)

## Tools
- Power BI Desktop
- Basic DAX
